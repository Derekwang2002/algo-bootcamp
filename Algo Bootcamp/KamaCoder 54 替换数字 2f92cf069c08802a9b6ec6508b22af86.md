给定一个字符串 s，它包含小写字母和数字字符，请编写一个函数，将字符串中的字母字符保持不变，而将每个数字字符替换为number。 例如，对于输入字符串 "a1b2c3"，函数应该将其转换为 "anumberbnumbercnumber"。

</aside>

- Timer: ***20min***
- Thought process:
    - 用**Stringbuilder** `res`作为拼接字符和“number”的容器
    - 用字符编码检验字符是否是数字：
    
    ```java
    chars[i] - '0' >= 0 && chars[i] - '0' <= 9
    ```
    
    - 返回`res.toString()`
- Evaluatoin:
    - Regular expression would be shorter code
    - Familiar with Java I/O, functions keywords, and class sructure.

# Solution

```java
import java.util.Scanner;
public class Main {
    public static void main(String[] args) {
        Scanner scanner = new Scanner(System.in);
        String s = scanner.nextLine();
        System.out.println(replaceNumbers(s));
    }

    private static String replaceNumbers(String s) {
        char[] chars = s.toCharArray();
        StringBuilder res = new StringBuilder();

        for (int i = 0; i < chars.length; i++) {
            if (
                chars[i] - '0' >= 0 
                && chars[i] - '0' <= 9
            ) { res.append("number"); }
            else {
                res.append(chars[i]);
            }
        }

        return res.toString();
    }
}
```
