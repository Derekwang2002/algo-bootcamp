<aside>
💡

Given an integer `n`, break it into the sum of `k` **positive integers**, where `k >= 2`, and maximize the product of those integers.

Return *the maximum product you can get*.

</aside>

# Thought

- Trick: every number ≥ 5 must contain 2 or 3 as a factor
- DP State: dp[i]=maximum product obtainable by breaking integer i
- DP equation: dp[i]=max(2⋅dp[i−2],3⋅dp[i−3])
    - for i ≥ 5
- Base case: dp[2]=2, dp[3]=3, dp[4]=4
    - 5 - 3 == 2, so set 234 as base case

# Solution

```java
class Solution {
    public int integerBreak(int n) {
        if (n <= 4) return (n / 2) * (n - n / 2);

        int[] memo = new int[3];
        memo[0] = 2;
        memo[1] = 3;
        memo[2] = 4;
        
        for (int i = 5; i <= n; i++) {
            int dp = Math.max(3 * memo[0], 2 * memo[1]);
            memo[0] = memo[1];
            memo[1] = memo[2];
            memo[2] = dp;
        }

        return memo[2];
    }
}
```
