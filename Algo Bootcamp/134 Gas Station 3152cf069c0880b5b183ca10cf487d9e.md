<aside>
💡

There are `n` gas stations along a circular route, where the amount of gas at the `ith` station is `gas[i]`.

You have a car with an unlimited gas tank and it costs `cost[i]` of gas to travel from the `ith` station to its next `(i + 1)th` station. You begin the journey with an empty tank at one of the gas stations.

Given two integer arrays `gas` and `cost`, return *the starting gas station's index if you can travel around the circuit once in the clockwise direction, otherwise return* `-1`. If there exists a solution, it is **guaranteed** to be **unique**.

</aside>

# Thought

- Only care about: deviation[i] = gas[i] - cost[i]
- 2 cases:
    1. No solution: sum(deviation[i]) < 0
    2. Exist unique solution: 
        - In a success loop, sum(deviation[i]) always > 0
- Greedy strategy(some i is start index):
    - Try start index with index of first non-negative deviation[i],
    - If sum(deviation[i]) < 0 at some point:
        - renew strat index to next index of non-negative deviation[i]

# Solution

### Improved (faster)

```java
class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int idx = -1;
        int sum = 0;

        for (int i = 0; i < gas.length; i++) {
            sum += gas[i] - cost[i];
        }

        if (sum < 0) {
            return -1;
        }

        for (int i = 0; i < gas.length; i++) { // gurantee to find a solution
            int dev = gas[i] - cost[i];

            if (idx == -1 && dev >= 0) { // greedy
                idx = i;
                sum = 0;
            }

            if (idx != -1) {
                sum += dev;
            }
            
            if (sum < 0) {
                idx = -1;
            }
        }

        return idx;
    }
}
```

class Solution {
    public int canCompleteCircuit(int[] gas, int[] cost) {
        int curSum = 0;
        int totalSum = 0;
        int index = 0;
        for (int i = 0; i < gas.length; i++) {
            curSum += gas[i] - cost[i];
            totalSum += gas[i] - cost[i];
            if (curSum < 0) {
                index = (i + 1) % gas.length ;
                curSum = 0;
            }
        }
        if (totalSum < 0) return -1;
        return index;
    }
}
