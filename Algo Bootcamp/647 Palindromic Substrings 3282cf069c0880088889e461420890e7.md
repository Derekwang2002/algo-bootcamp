<aside>
💡

Given a string `s`, return *the number of **palindromic substrings** in it*.

A string is a **palindrome** when it reads the same backward as forward.

A **substring** is a contiguous sequence of characters within the string.

</aside>

# Thought

> *Dynamic programming | Double pointer*
> 

## Dynamic programming

### Method 1

- DP state: dp(i,j) → (boolean)if s[i,j] is palindromic
    - j ≥ i
- DP equation:
    - dp(i,j) = false, if s[i] ≠ s[j]
    - dp(i,j) = true, if (i == j) or (j-i == 1 && s[i] == s[j])
    - dp(i,j) = dp(i+1,j-1), if (j-i > 1 && s[i] == s[j])
- Table (`s = "abaaba”`):

```java
				j=0(a)  j=1(b)  j=2(a)  j=3(a)  j=4(b)  j=5(a)
      +-------+-------+-------+-------+-------+-------+
i=0(a)|   T   |       |   T   |       |       |   T   | -> "a","aba","abaaba"
      +-------+-------+-------+-------+-------+-------+
i=1(b)|       |   T   |       |       |   T   |       | -> "b", "baab"
      +-------+-------+-------+-------+-------+-------+
i=2(a)|       |       |   T   |   T   |       |       | -> "a", "aa"
      +-------+-------+-------+-------+-------+-------+
i=3(a)|       |       |       |   T   |       |       | -> "a"
      +-------+-------+-------+-------+-------+-------+
i=4(b)|       |       |       |       |   T   |       | -> "b"
      +-------+-------+-------+-------+-------+-------+
i=5(a)|       |       |       |       |       |   T   | -> "a"
      +-------+-------+-------+-------+-------+-------+
```

- Complexity:
    - time - O(n^2)
    - space - O(n)

### Method 2

- DP state: dp(i) = **array of lengths** of palindromic substring end with ith character of s.
- Base case: dp(i)[0] = 1 (single character)
- DP equation:
    - dp(i).add(2), if s[i] == s[i-1]
    - dp(i).add(l + 2), if s[i] == s[i-l-1], for l in dp(i-1)
- Complexity:
    - time - O(n^2)
    - space - O(n)

## Double pointer (central expansion)

- Fixing a center (single/double), #palindromic substring with current center could be determined by expansion double pointer.
- Traverse all center of a string and record the #palindromic subtring

# Solution

## Dynamic Programming

### Method 1

```java
class Solution {
    public int countSubstrings(String s) {
        boolean[][] dp = new boolean[s.length()][s.length()];

        int res = 0;
        for (int i = s.length() - 1; i >= 0; i--) {
            for (int j = i; j < s.length(); j++) {
                if (s.charAt(i) == s.charAt(j) && (j - i <= 1 || dp[i + 1][j - 1])) {
                    res++;
                    dp[i][j] = true;
                }
            }
        }
        return res;
    }
}
```

### Method 2

```java
class Solution {
    public int countSubstrings(String s) {
        int ans = 1;
        List<Integer> dp = new ArrayList<>();
        dp.add(1);

        for (int i = 1; i < s.length(); i++) {
            char cur = s.charAt(i);
            List<Integer> temp = new ArrayList<>();
            temp.add(1);

            if (cur == s.charAt(i - 1)) {
                temp.add(2);
            }

            for (int l : dp) {
                if (i - l - 1 >= 0 && cur == s.charAt(i - l - 1)) {
                    temp.add(l + 2);
                }
            }

            dp = new ArrayList<>(temp);
            ans += dp.size();
        }

        return ans;
    }
}
```

#### GPT Optimized

```java
class Solution {
    public int countSubstrings(String s) {
        int n = s.length();
        if (n == 0) return 0;

        char[] arr = s.toCharArray();

        int ans = 1;
        int[] dp = new int[n];
        int size = 1;
        dp[0] = 1; // 以 0 结尾的回文长度集合：{1}

        for (int i = 1; i < n; i++) {
            int[] temp = new int[n];
            int k = 0;

            temp[k++] = 1; // 单字符回文

            if (arr[i] == arr[i - 1]) {
                temp[k++] = 2; // 双字符回文
            }

            for (int j = 0; j < size; j++) {
                int l = dp[j];
                if (i - l - 1 >= 0 && arr[i] == arr[i - l - 1]) {
                    temp[k++] = l + 2;
                }
            }

            dp = temp;
            size = k;
            ans += size;
        }

        return ans;
    }
}
```

## Double pointer

```java
class Solution {
    public int countSubstrings(String s) {
        int result = 0;

        for (int i = 0; i < s.length(); i++) { // traverse center
            result += extend(s, i, i);
            result += extend(s, i, i + 1);
        }

        return result;
    }

    private int extend(String s, int i, int j) { // determine #pali of the center
        int res = 0;

        while (i >= 0 && j < s.length() && s.charAt(i) == s.charAt(j)) {
            res++;
            i--;
            j++;
        }

        return res;
    }
}
```
