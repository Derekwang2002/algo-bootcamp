<aside>
💡

You are given an integer array `nums`. You are initially positioned at the array's **first index**, and each element in the array represents your maximum jump length at that position.

Return `true` *if you can reach the last index, or* `false` *otherwise*.

</aside>

# Thought

- Set nearest end as `nums.length - 1`
- Loop backward (`i` starts with second last):
    - if dist between `i` and nearest end is **no bigger** than nums[i], it means we can jump from `i` to nearest end, then renew nearest end to i.
    - `i` promised be able to jump to last index.
- After loop end, if nearest end is not 0, it means we can’t jump from first to last index, return false, vice versa.

# Solution

```java
class Solution {
    public boolean canJump(int[] nums) {
        int start = nums.length - 1; // last index

        // starts from second last
        for (int i = start - 1; i >= 0; i--) { 
            if ((start - i) <= nums[i]) {
                start = i;
            }
        }

        return start == 0;
    }
}
```
