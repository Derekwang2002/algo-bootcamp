Given an array of integers `nums` and an integer `target`, return *indices of the two numbers such that they add up to `target`*.

You may assume that each input would have ***exactly* one solution**, and you may not use the *same* element twice. (esay for map.put())

You can return the answer in any order.

# Thought:

- 初见时，暴力解，对数组中的元素遍历，每一个元素nums[i]在[i+1,nums.length)之间寻找匹配值。
- 再见时，哈希法，但本质思路一样，只不过换了个方向，对于nums[i]：
    - 在[0,i)之间的HashMap中寻找匹配值
    - 如果没有，则将nums[i]加入HashMap
    - 与暴力解的区别在于，内层循环搜索的时间复杂度降至O(1)
- Evaluation：
    - 掌握HashMap用法，以及底层容器，清楚何时使用

# Solution

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        int[] res = new int[2];

        for (int i = 0; i < nums.length; i++) {
            int sub_tar = target - nums[i];
            if (map.containsKey(sub_tar)) {
                res[0] = map.get(sub_tar);
                res[1] = i;
                break;
            } else {
                map.put(nums[i], i);
            }
        }

        return res;
    }
}
```
