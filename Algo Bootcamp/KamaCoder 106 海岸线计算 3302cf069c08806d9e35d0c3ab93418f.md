💡

给定一个由 1（陆地）和 0（水）组成的矩阵，岛屿是被水包围，并且通过水平方向或垂直方向上相邻的陆地连接而成的。

你可以假设矩阵外均被水包围。在矩阵中恰好拥有一个岛屿，假设组成岛屿的陆地边长都为 1，请计算海岸线，即：岛屿的周长。岛屿内部没有水域。

- input: 第一行包含两个整数 N, M，表示矩阵的行数和列数。之后 N 行，每行包含 M 个数字，数字为 1 或者 0，表示岛屿的单元格。
- output: 输出一个整数，表示岛屿的周长。
</aside>

# Thought

- Traverse island, when surround grid out bound or meet zero, perimeter++.

# Solution

```java
import java.util.*;

public class Main {
    static int[][] grid;
    static int[][] dirs = {{1, 0}, {-1, 0}, {0, 1}, {0, -1}};

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        int rows = in.nextInt();
        int cols = in.nextInt();
        grid = new int[rows][cols];

        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                grid[i][j] = in.nextInt();
            }
        }

        int res = 0;
        for (int i = 0; i < rows; i++) {
            for (int j = 0; j < cols; j++) {
                if (grid[i][j] == 1) res = dfs(i, j);
            }
        }

        System.out.println(res);
    }

    static int dfs(int r, int c) {
        int peri = 0;
        grid[r][c] = 2; // visited

        for (int[] dir : dirs) {
            int nr = r + dir[0];
            int nc = c + dir[1];
            boolean outBound = nr < 0 || nc < 0 || nr >= grid.length || nc >= grid[0].length;

            if (outBound || grid[nr][nc] == 0) {
                peri++;
                continue;
            }

            if (grid[nr][nc] == 1) {
                peri += dfs(nr, nc);
            }
        }

        return peri;
    }
}
```
