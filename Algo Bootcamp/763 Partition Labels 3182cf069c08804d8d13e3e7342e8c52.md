<aside>
💡

You are given a string `s`. We want to partition the string into as many parts as possible so that each letter appears in at most one part. For example, the string `"ababcc"` can be partitioned into `["abab", "cc"]`, but partitions such as `["aba", "bcc"]` or `["ab", "ab", "cc"]` are invalid.

Note that the partition is done so that after concatenating all the parts in order, the resultant string should be `s`.

Return *a list of integers representing the size of these parts*.

</aside>

# Thought

- Greedy Strategy
    - First extract **interval of each letter** in the string
        - interval: [1st appear index(start) - last appear index(end)]
    - **Sort by the start index**, then traverse
        - record previous max end index(renew at each step), and last cut line(index)
        - **if current start index > previous max end index**
            - record substring length and renew last cut line
        - Why? because we need to get info of former appeared letter first
            - if sort by end index, it will failed when like:
            
            ```
              [--b--] [-c-]
            [--------a------]
            ```
            

# Solution

```java
class Solution {
    public List<Integer> partitionLabels(String s) {
        int[][] alphabet = new int[26][2];
        char head = s.charAt(0);

        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            int[] cur = alphabet[c - 'a'];

            if (cur[0] == 0 && c != head) { // first met
                cur[0] = i;
            }

            cur[1] = i;
        }

        int x = -1; // previous cut line
        int prevEnd = alphabet[head - 'a'][1]; // previos max interval end
        List<Integer> res = new ArrayList<>();

        Arrays.sort(alphabet, (a, b) -> {
            return a[0] - b[0];
        });
        
        for (int[] c : alphabet) {
            if (c[1] == 0) continue;
            
            if (c[0] > prevEnd) {
                res.add(prevEnd - x);
                x = prevEnd;
            }

            prevEnd = Math.max(c[1], prevEnd); // c[1] >= c[0] > prevEnd
        }

        res.add(prevEnd - x);
        return res;
    }
}
```
