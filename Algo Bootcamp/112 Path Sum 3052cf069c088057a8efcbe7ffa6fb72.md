<aside>
💡

Given the `root` of a binary tree and an integer `targetSum`, return `true` if the tree has a **root-to-leaf** path such that adding up all the values along the path equals `targetSum`.

A **leaf** is a node with no children.

</aside>

# Thought:

- like find all path, plus a record of if find target path sum
    - Since path, use DFS backtracking for sum tracker.
    - Method 1:
        - return *void*, and (`TreeNode root, int sum`)
        - set a gloabal boolean variable result default false,
        - **accumulate sum** at each step, when met target sum, set it to true. (still continue recursion)
        - base case: leaf node
    - Method 2:
        - return *boolean*, and (`TreeNode node, int decrementor`)
        - if return is true, return function, jump over recursion.
        - Use a **decrementor parameter** for recursion fnuction.(set to targerSum at first, then subtract node.val at each level)

# Solution

## DFS Backtracking

```java
class Solution {
    boolean result = false;
    int targetSum;

    public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root != null) {
            this.targetSum = targetSum;
            sumPath(root, 0);
        }
        return result;
    }

    private void sumPath(TreeNode root, int sum) {
        int temp = sum;
        sum += root.val;

        if (root.left == null && root.right == null) {
            if (sum == targetSum) {
                result = true;
            } 
        } else {
            if (root.left != null) {
                sumPath(root.left, sum);
            }
            if (root.right != null) {
                sumPath(root.right, sum);
            }
        }

        sum = temp;
    }
}
```

## Smarter implementation

```java
class Solution {
   public boolean hasPathSum(TreeNode root, int targetSum) {
        if (root == null) {
            return false;
        }
        targetSum -= root.val;
        // 叶子结点
        if (root.left == null && root.right == null) {
            return targetSum == 0;
        }
        if (root.left != null) {
            boolean left = hasPathSum(root.left, targetSum);
            if (left) {      // 已经找到，提前返回
                return true;
            }
        }
        if (root.right != null) {
            boolean right = hasPathSum(root.right, targetSum);
            if (right) {     // 已经找到，提前返回
                return true;
            }
        }
        return false;
    }
}

// 简洁方法
class Solution {
    public boolean hasPathSum(TreeNode root, int targetSum) {

        if (root == null) return false; // 为空退出

        // 叶子节点判断是否符合
        if (root.left == null && root.right == null) return root.val == targetSum;

        // 求两侧分支的路径和
        return hasPathSum(root.left, targetSum - root.val) || hasPathSum(root.right, targetSum - root.val);
    }
}
```
