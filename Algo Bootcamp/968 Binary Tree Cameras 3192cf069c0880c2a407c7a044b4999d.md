<aside>
💡

You are given the `root` of a binary tree. We install cameras on the tree nodes where each camera at a node can monitor its parent, itself, and its immediate children.

Return *the minimum number of cameras needed to monitor all nodes of the tree*.

</aside>

# Thought

- Greedy strategy:
    - **only** set camera when needed → some of children are not monitored
    - monitored nodes: some of the children are camera
    - not monitored nodes: non of the children is camera
- Implementation:
    - Check the root status in main function
    - Implement logic in a helper function.
- Similar to: [337. House Robber III](337%20House%20Robber%20III%203212cf069c0880329925f71d93ecb66a.md)

# Solution

```java
class Solution {
    int count = 0;
    
    public int minCameraCover(TreeNode root) {
        if (camera(root) == -1) {
            count++;
        }
        
        return count;
    }

    private int camera(TreeNode root) {
        if (root == null) {
            return 0;
        }

        int left = camera(root.left);
        int right = camera(root.right);

        if (left == -1 || right == -1) { 
        // some of the children need monitor, must set camera
            count++; 
            return 1;
        }

        if (left == 1 || right == 1) { 
        // no (-1 / monitor) need, which is monitored by children
            return 0;
        }

        // left == right == 0 -> not monitored, need monitor of parent.
        return -1;

    }
}
```
