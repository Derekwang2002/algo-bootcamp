<aside>
💡

Given two integers `n` and `k`, return *all possible combinations of* `k` *numbers chosen from the range* `[1, n]`.

You may return the answer in **any order**.

</aside>

# Thought:

- Virtual recursion tree, use stack to store
    - Tree structure
        - Root(dummy) → 0
        - Layer → k + 1 (1 is for 0 layer)
        - #subnodes: (n - parent value)
    - Recursion design:
        - Return void, take a counter and a stack as parameters
        - Base case: stack.size() == k
        - Adding: if n ≠ 0, then push(at very first)
        - Backtracking step: before every return, pop one element

# Solution

## Raw (less memory)

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    int n;
    int k;
    public List<List<Integer>> combine(int n, int k) {
        this.n = n;
        this.k = k;
        Deque<Integer> stack = new ArrayDeque<>();
        backtracking(0, stack);
        return res;
    }

    private void backtracking(int n, Deque<Integer> stack) {
        if (this.n - n + 1 < k - stack.size()) { /// pruning
            return;
        }

        if (n != 0) {
            stack.push(n);
        }
        

        if (stack.size() == k) {
            res.add(new ArrayList(stack));
            stack.pop();
            return;
        } 

        for (int i = n + 1; i <= this.n; i++) {
            backtracking(i, stack);
        }

        if (!stack.isEmpty()) {
            stack.pop();
        }
    }
}
```

## Carl’s (cleaner)-can be reduced from raw version

```java
class Solution {
    List<List<Integer>> result = new ArrayList<>();
    LinkedList<Integer> path = new LinkedList<>();
    public List<List<Integer>> combine(int n, int k) {
        combineHelper(n, k, 1);
        return result;
    }

    /**
     * 每次从集合中选取元素，可选范围随着选择的进行而收缩，调整可选择的范围，就是要靠startIndex
     * @param startIndex 用来记录本层递归的中，集合从哪里开始遍历（集合就是[1,...,n] ）
     */
    private void combineHelper(int n, int k, int startIndex){
        //终止条件
        if (path.size() == k){
            result.add(new ArrayList<>(path));
            return;
        }
        for (int i = startIndex; i <= n - (k - path.size()) + 1; i++){
            path.add(i);
            combineHelper(n, k, i + 1);
            path.removeLast();
        }
    }
}
```
