Given the `root` of a binary tree and an integer `targetSum`, return *all **root-to-leaf** paths where the sum of the node values in the path equals* `targetSum`*. Each path should be returned as a list of the node **values**, not node references*.

A **root-to-leaf** path is a path starting from the root and ending at any leaf node. A **leaf** is a node with no children.

</aside>

# Thought:

- Use a global variable to store result list.
- Return type `void`, store `sum,path` as parameters.
- Similar to [257. Binary Tree Path](257%20Binary%20Tree%20Path%203052cf069c0880349f75c2dcbc2900d2.md) , for this problem we use ArrayList to store path, and add to result only when the sum is equal to target.
- Evaluation
    - Important: **reference passing** wihtin recursion steps, and backtracking method.

# Solution

## DFS backtracking

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();

    public List<List<Integer>> pathSum(TreeNode root, int targetSum) {
        if (root != null) {
            sumPath(root, targetSum, new ArrayList<>());
        }
        return res;
    }

    private void sumPath(TreeNode root, int sum, List<Integer> path) {
        int len = path.size();
        path.add(root.val);

        if (root.left == null && root.right == null) {
            if (sum == root.val) {
                res.add(new ArrayList<>(path));
            }
        } else {
            if (root.left != null) {
                sumPath(root.left, sum - root.val, path);
            }
            if (root.right != null) {
                sumPath(root.right, sum - root.val, path);
            }
        }

        while (path.size() > len) {
            path.remove(path.size() - 1);
        }
    }
}
```
