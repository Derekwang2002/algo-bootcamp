The thief has found himself a new place for his thievery again. There is only one entrance to this area, called `root`.

Besides the `root`, each house has one and only one parent house. After a tour, the smart thief realized that all houses in this place form a binary tree. It will automatically contact the police if **two directly-linked houses were broken into on the same night**.

Given the `root` of the binary tree, return *the maximum amount of money the thief can rob **without alerting the police***.

</aside>

# Thought

- **DP state:** dp[root] → max value of subtree with current root.
- **Base case:** dp[null] = 0
- **DP equation:**
    
    $$
    dp[root] = max\{root.val + dp[root.chilren.children],\ dp[root.children]\}
    $$
    
    - Denotion:
        - **dp[root.chilren.children]** → dp[root.left.children] + dp[root.right.children]
        - **dp[root.children]** → dp[root.left] + dp[root.right]
    - Case 1: choose root and root’s children’s children
    - Case 2: choose root’s children
- **Implementation:**
    - return of each node:
        - int[] → {dp[root], dp[roo.left] + dp[root.right]}
- Similar to: [968. Binary Tree Cameras](968%20Binary%20Tree%20Cameras%203192cf069c0880c2a407c7a044b4999d.md)

# Solution

```java
class Solution {
    public int rob(TreeNode root) {
        return robTree(root)[1];
    }

    private int[] robTree(TreeNode root) {
        int[] dp = new int[2];
        if (root == null) return dp;
        
        int[] left = robTree(root.left);
        int[] right = robTree(root.right);

        dp[0] = left[1] + right[1];
        dp[1] = Math.max(root.val + left[0] + right[0], dp[0]);

        return dp;
    }
}
```
