<aside>
💡

字典 strList 中从字符串 beginStr 和 endStr 的转换序列是一个按下述规格形成的序列：

1. 序列中第一个字符串是 beginStr。
2. 序列中最后一个字符串是 endStr。
3. 每次转换只能改变一个字符。
4. 转换过程中的中间字符串必须是字典 strList 中的字符串，且strList里的每个字符串只用使用一次。

给你两个字符串 beginStr 和 endStr 和一个字典 strList，找到从 beginStr 到 endStr 的最短转换序列中的字符串数目。如果不存在这样的转换序列，返回 0。

- input: 第一行包含一个整数 N，表示字典 strList 中的字符串数量。 第二行包含两个字符串，用空格隔开，分别代表 beginStr 和 endStr。 后续 N 行，每行一个字符串，代表 strList 中的字符串。
- output: 输出一个整数，代表从 beginStr 转换到 endStr 需要的最短转换序列中的字符串数量。如果不存在这样的转换序列，则输出 0。
</aside>

# Thought

- Build graph → use `Map<String, List<String>>` to represent the neighbor strings that **has exectly 1 edit distance** to a certain string
    - undirected(except begin/end string)
- Do BFS on this graph, and count minimum steps: `beginStr` → `endStr`
    - Layer control trick: use `que.size()` to limit within one layer

# Solution

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Map<String, List<String>> neighbor = new HashMap<>();
        Scanner in = new Scanner(System.in);

        int n = in.nextInt();
        String beginStr = in.next();
        String endStr = in.next();

        neighbor.put(beginStr, new ArrayList<>());
        neighbor.put(endStr, new ArrayList<>());

        String[] strList = new String[n];

        for (int i = 0; i < n; i++) {
            strList[i] = in.next();
            neighbor.put(strList[i], new ArrayList<>());

            if (ifNear(beginStr, strList[i])) neighbor.get(beginStr).add(strList[i]);
            if (ifNear(endStr, strList[i])) neighbor.get(strList[i]).add(endStr);
        }

        for (int i = 0; i < n; i++) {
            for (int j = i + 1; j < n; j++) {
                if (ifNear(strList[i], strList[j])) {
                    neighbor.get(strList[i]).add(strList[j]);
                    neighbor.get(strList[j]).add(strList[i]);
                }
            }
        }

        Set<String> vis = new HashSet<>();
        Deque<String> que = new ArrayDeque<>();
        que.offer(beginStr);

        int size = 1;
        int childs = 0;
        int steps = 2; // begin + end

        while (!que.isEmpty()) {
            String cur = que.poll();
            
            if (neighbor.get(cur).contains(endStr)) {
                System.out.print(steps);
                return;
            } 

            for (String s : neighbor.get(cur)) {
                if (vis.add(s)) {
                    que.offer(s);
                    childs++;
                }
            }

            if (--size == 0) {
                steps++;
                size = childs;
                childs = 0;                
            }
        }

        System.out.print(0);
    }

    static boolean ifNear(String s1, String s2) {
        int dist = 0;

        for (int i = 0; i < s1.length(); i++) {
            if (s1.charAt(i) != s2.charAt(i)) dist++;
            if (dist > 1) return false;
        }

        return dist == 1;
    }
}
```
