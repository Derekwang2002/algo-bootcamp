Given four integer arrays `nums1`, `nums2`, `nums3`, and `nums4` all of length `n`, return the number of tuples `(i, j, k, l)` such that:

- `0 <= i, j, k, l < n`
- `nums1[i] + nums2[j] + nums3[k] + nums4[l] == 0`
</aside>

# Thought:

- 开始找到了正确的思路：将数组两两各自求和，得到一个HashMap存储的结果
- 代码细节：
    - HashMap：求和作key，计数作value，res统计nums1&2的求和结果
    - 再遍历nums3&4，运用TwoSum思想 更新res，最简思路：
    
    ```java
    res += sum12.getOrDefault(0 - i - j, 0);
    ```
    
    - 重复put相同的key会造成覆盖，计数解决方法:
    
    ```java
    sum12.put(key, sum12.getOrDefault(key, 0) + 1);
    ```
    
- Evaluation:
    - 善用 **map.getOrDefault(key,0)**;
    - HashMap用法的考察

# 原

```java
class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        Map<Integer, Integer> sum12 = new HashMap<>();
        Map<Integer, Integer> sum34 = new HashMap<>(); // useless

        for (int i = 0; i < nums1.length; i++){
            for (int j = 0; j < nums2.length; j++){
                int key = nums1[i] + nums2[j];
                sum12.put(key, sum12.getOrDefault(key, 0) + 1);
            }
        }

        for (int i = 0; i < nums3.length; i++){
            for (int j = 0; j < nums4.length; j++){
                int key = nums3[i] + nums4[j];
                sum34.put(key, sum34.getOrDefault(key, 0) + 1); // useless
            }
        }

        int res = 0;
        for (Integer sum: sum12.keySet()) { // put this step into forfor loop in nums34
            int temp = 0 - sum;
            // use res += getOrDefault(key, 0) to compute would be faster
            if (sum34.containsKey(temp)) {res += (sum12.get(sum) * sum34.get(temp));}
        }

        return res;
    }
}
```

# 优化后

```java
class Solution {
    public int fourSumCount(int[] nums1, int[] nums2, int[] nums3, int[] nums4) {
        Map<Integer, Integer> sum12 = new HashMap<>();

        for (int i : nums1){
            for (int j : nums2){
                int key = i + j;
                sum12.put(key, sum12.getOrDefault(key, 0) + 1);
            }
        }

        int res = 0;

        for (int i : nums3){
            for (int j : nums4){
                res += sum12.getOrDefault(0 - i - j, 0);
            }
        }

        return res;
    }
}
```
