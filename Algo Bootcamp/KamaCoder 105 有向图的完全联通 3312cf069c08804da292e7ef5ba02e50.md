💡

给定一个有向图，包含 N 个节点，节点编号分别为 1，2，...，N。现从 1 号节点开始，如果可以从 1 号节点的边可以到达任何节点，则输出 1，否则输出 -1。

- input：第一行包含两个正整数，表示节点数量 N 和边的数量 K。 后续 K 行，每行两个正整数 s 和 t，表示从 s 节点有一条边单向连接到 t 节点。
- output: 如果可以从 1 号节点的边可以到达任何节点，则输出 1，否则输出 -1。
</aside>

# Thought

- Use adjacent table to store directed graph
- Do dfs and store visited nodes
    - if visited, skip → avoid circle
    - check if visited all nodes at last

# Solution

```java
import java.util.*;

public class Main {
    static List<Integer>[] g;
    static Set<Integer> vis = new HashSet<>();

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        int n = in.nextInt();
        int k = in.nextInt();

        g = new List[n + 1];
        for (int i = 0; i <= n; i++) {
            g[i] = new ArrayList<>();
        }

        for (int i = 0; i < k; i++) {
            g[in.nextInt()].add(in.nextInt());
        }

        dfs(1);

        int res = -1;
        if (vis.size() == n) res = 1;
        System.out.print(res);
    }

    static void dfs(int node) {
        if (!vis.add(node)) return;
        for (int i : g[node]) dfs(i);
    }
}
```
