You are given an integer array `nums` and an integer `target`.

You want to build an **expression** out of nums by adding one of the symbols `'+'` and `'-'` before each integer in nums and then concatenate all the integers.

- For example, if `nums = [2, 1]`, you can add a `'+'` before `2` and a `'-'` before `1` and concatenate them to build the expression `"+2-1"`.

Return the number of different **expressions** that you can build, which evaluates to `target`.

</aside>

# Thought

- Trick: find num[i]s that sum up to {`target` → `(sum - target) / 2`}
    - which is to find the negative part of the nums.
- DP state: dp[j]=number of ways to select numbers whose sum equals j
- Base case: dp[0]=1
    - means choose nothing
- DP equation: $dp[j]=dp[j]+dp[j−n] (j≥n)$
    - $n$ : from num[0] to n could be used to choose
    - dp[j]: not use n
    - dp[j−n]: use n
- DP table: ({1, 1, 2 ,3}, 1)

```
capacity j →    0   1   2   3
items used ↓   -----------------
{}              1   0   0   0
{1}             1   1   0   0
{1,1}           1   2   1   0
{1,1,2}         1   2   2   2
{1,1,2,3}       1   2   2   3
```

# Solution

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int n : nums) sum += n;

        int dif = (sum - target);
        int ne = dif / 2;
        if (dif % 2 != 0 || dif < 0) return 0; // invalid cases

        int[] dp = new int[ne + 1];
        dp[0] = 1;

        for (int n : nums) {
            for (int j = ne; j >= n; j--) {
                dp[j] += dp[j - n];
            }
        }

        return dp[ne];
    }
}
```

### Optimized

```java
class Solution {
    public int findTargetSumWays(int[] nums, int target) {
        int sum = 0;
        for (int n : nums) sum += n;

        // OPTIMIZATION: Absolute target check prevents out-of-bounds or massive negative targets
        if (Math.abs(target) > sum || (sum - target) % 2 != 0) {
            return 0; 
        }

        int ne = (sum - target) / 2;

        int[] dp = new int[ne + 1];
        dp[0] = 1;

        for (int n : nums) {
            // The 1D array traverses backwards to use values from the previous state seamlessly
            for (int j = ne; j >= n; j--) {
                dp[j] += dp[j - n];
            }
        }

        return dp[ne];
    }
}
```
