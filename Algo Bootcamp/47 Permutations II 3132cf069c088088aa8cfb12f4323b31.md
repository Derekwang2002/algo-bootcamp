# Thought

- Implement deduplication:
    - record last used number within same loop(level)
    - if current number equals last used number, continue
- For swap approach: use a Set to layer-dedup

# Solution

```java
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        // Use a boolean array to track POSITIONS, not values.
        // This makes it O(1) lookup and compatible with any number range.
        boolean[] used = new boolean[nums.length];

        Arrays.sort(nums); // presort to dedup
        
        backtrack(nums, used, new ArrayList<>(nums.length), res);
        return res;
    }

    private void backtrack(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> res) {
        // Base case: path is full
        if (path.size() == nums.length) {
            res.add(new ArrayList<>(path));
            return;
        }

        int last = nums[0] - 1; // less than all number in nums
        for (int i = 0; i < nums.length; i++) {
            // Skip: if this poisiton used OR euqal ot last one in same level
            if (used[i] || (nums[i] == last)) {
                continue;
            }

            path.add(nums[i]);
            used[i] = true;

            backtrack(nums, used, path, res);

            used[i] = false;
            path.remove(path.size() - 1);

            last = nums[i];
        }
    }
}
```

## Swap

```java
class Solution {
    public List<List<Integer>> permuteUnique(int[] nums) {
        List<List<Integer>> res = new ArrayList<>();
        backtrack(0, nums, res);
        return res;
    }

    private void backtrack(int start, int[] nums, List<List<Integer>> res) {
        if (start == nums.length) {
            List<Integer> path = new ArrayList<>();
            for (int num : nums) path.add(num);
            res.add(path);
            return;
        }

        // 局部 HashSet：记录在 start 这个位置上，哪些数字已经尝试过了
        Set<Integer> usedInLevel = new HashSet<>();

        for (int i = start; i < nums.length; i++) {
            // 如果这个数字在当前层已经交换过一次了，直接跳过
            if (!usedInLevel.add(nums[i])) {
                continue;
            }

            swap(nums, start, i);
            backtrack(start + 1, nums, res);
            swap(nums, start, i);
        }
    }

    private void swap(int[] nums, int i, int j) {
        int temp = nums[i];
        nums[i] = nums[j];
        nums[j] = temp;
    }
}
```
