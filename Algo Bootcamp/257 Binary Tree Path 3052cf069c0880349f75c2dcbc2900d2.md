# 257. Binary Tree Path

Minutes: 60

<aside>
💡

Given the `root` of a binary tree, return *all root-to-leaf paths in **any order***.

A **leaf** is a node with no children.

</aside>

- Timer: **1h+**
- Thought:
    - **DFS recursion(postorder)**:
        - return type is List<String> and parameter is TreeNode
        - each step, combine childs lists, add current node.val as prefix for all
        - base case: when current node is null, return an empty list; and if the combine of childs are empty, return current node.val as a list.
    - **Top down backtracking(preorder)**:
        - return void, paras:`(TreeNode node, StringBuilder path, List<String> res)`
        - at each node, do add self to path(use `StringBuilder`!), then pass the path to its children(not null), then do backtracing.
        - base case: when meet leaf node, add full path to res.

# Solution

## Bottom up

```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        if (root == null) {
            return new ArrayList<>();
        }

        List<String> res = binaryTreePaths(root.left);
        res.addAll(binaryTreePaths(root.right));

        if (res.isEmpty()) {
            return new ArrayList<>(List.of(String.valueOf(root.val)));
        }

        res.replaceAll(s -> root.val + "->" + s);

        return res;
    }
}
```

## Top down (with Backtracking)

```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> res = new ArrayList<>();
        paths(root, "", res);
        return res;
    }

    private void paths(TreeNode node, String path, List<String> res) {
        if (node.left == null && node.right == null) {
            res.add(path + node.val);
        }

        path = path + node.val + "->";

        if (node.left != null) {
            paths(node.left, path, res);
        }

        if (node.right != null) {
            paths(node.right, path, res);
        }
    }
}
```

`path` 在进入 left 递归和 right 递归时，指向的是同一个旧字符串对象（不可变），left 里面就算做了 `path = path + ...`，也只是把 **left 那一层栈帧里的局部变量 path** 改指向了新字符串，不会影响 parent，更不会影响 right。

因此：**天然“回溯效果”已经由不可变性 + 栈帧隔离实现了**。

## Modified Backtracking (best)

```java
class Solution {
    public List<String> binaryTreePaths(TreeNode root) {
        List<String> res = new ArrayList<>();
        paths(root, new StringBuilder(), res);
        return res;
    }

    private void paths(TreeNode node, StringBuilder path, List<String> res) {
        int len = path.length();
        path.append(node.val);

        if (node.left == null && node.right == null) { // determine if leaf
            res.add(path.toString());
        } else {
            path.append("->");
        }

        if (node.left != null) {
            paths(node.left, path, res);
        }

        if (node.right != null) {
            paths(node.right, path, res);
        }

        path.setLength(len);
    }
}
```
