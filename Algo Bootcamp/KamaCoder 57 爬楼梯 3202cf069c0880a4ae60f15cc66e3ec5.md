💡

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬至多m (1 <= m < n)个台阶。你有多少种不同的方法可以爬到楼顶呢？

注意：给定 n 是一个正整数。

- input: 输入共一行，包含两个正整数，分别表示n, m
- output: 输出一个整数，表示爬到楼顶的方法数。
</aside>

# Solution

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();
        int m = in.nextInt();

        int[] dp = new int[n + 1];
        dp[0] = 1;

        for (int i = 1; i <= n; i++) { // stairs
            for (int j = 1; j <= m; j++) { // exact step length
                if (j > i) continue;
                dp[i] += dp[i - j];
            }
        }

        System.out.print(dp[n]);
    }
}
```
