💡

某个大型软件项目的构建系统拥有 N 个文件，文件编号从 0 到 N - 1，在这些文件中，某些文件依赖于其他文件的内容，这意味着如果文件 A 依赖于文件 B，则必须在处理文件 A 之前处理文件 B （0 <= A, B <= N - 1）。请编写一个算法，用于确定文件处理的顺序。

- input: 第一行输入两个正整数 N, M。表示 N 个文件之间拥有 M 条依赖关系。后续 M 行，每行两个正整数 S 和 T，表示 T 文件依赖于 S 文件。
- output: 输出共一行，如果能处理成功，则输出文件顺序，用空格隔开。如果不能成功处理（相互依赖），则输出 -1。
</aside>

# Thought

- Theory: [Topological Sort](https://app.notion.com/p/Topological-Sort-3342cf069c0880eeaf2bd5258ce66f30?pvs=21)
- Detail: when delete a node, subtract its childs’ in-degree by 1

# Solution

```java
import java.util.*;

public class Main {
    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);

        int n = in.nextInt();
        int m = in.nextInt();

        int[] inDegree = new int[n];
        List<Integer>[] graph = new List[n];

        for (int i = 0; i < n; i++) {
            graph[i] = new ArrayList<>();
        }

        // read input
        while (m-- > 0) {
            int s = in.nextInt();
            int t = in.nextInt();

            graph[s].add(t); // s is prerequisite of t, t rely on s
            inDegree[t]++;
        }

        // bfs docker, store 0-in-degree nodes
        Deque<Integer> roots = new ArrayDeque<>();

        // store processed files
        List<Integer> res = new ArrayList<>();

        // delete nodes with 0 in-degree
        for (int i = 0; i < n; i++) {
            if (inDegree[i] == 0) roots.offer(i);
        }

        // bfs
        while (!roots.isEmpty()) {
            int r = roots.poll();
            res.add(r);

            // delete edges
            for (int v : graph[r]) {
                inDegree[v]--;

                // renew
                if (inDegree[v] == 0) roots.offer(v);
            }
        }

        if (res.size() != n) {
            System.out.print(-1);
            return;
        }

        for (int i = 0; i < n; i++) {
            System.out.print(res.get(i));

            if (i != n - 1) {
                System.out.print(" ");
            }
        }
    }
}
```
