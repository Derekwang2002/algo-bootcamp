Given an array `nums` of `n` integers, return *an array of all the **unique** quadruplets* `[nums[a], nums[b], nums[c], nums[d]]` such that:

- `0 <= a, b, c, d < n`
- `a`, `b`, `c`, and `d` are **distinct**.
- `nums[a] + nums[b] + nums[c] + nums[d] == target`

You may return the answer in **any order**.

</aside>

# Thought:

- Almost same as 3Sum, just one more layer of loop
- Care of **pruning condition**, and **deduplication**
- !!max number of sum will exceed size of `int` type (bit overflow), use `long` to avoid
- Evaluation:
    - 3Sum plus
    - good for practice

# Solution

```java
class Solution {
    public List<List<Integer>> fourSum(int[] nums, int target) {
        // a+b+c+d == target
        List<List<Integer>> res = new ArrayList<>();
        Arrays.sort(nums);
        
        for (int i = 0; i < nums.length - 3; i++) {
		        if (nums[i] > target && nums[i] >= 0) { break; } // prune
            if (i > 0 && nums[i] == nums[i-1]) { continue; } // dedup

            for (int j = i + 1; j < nums.length - 2; j++) { 
		            if (nums[i] + nums[j] > target && nums[j] >= 0) { break; } // prune
                if (j > i + 1 && nums[j] == nums[j-1]) { continue; } // dedup

                int left = j + 1;
                int right = nums.length - 1;

                while (left < right) {
                    int tempSum = nums[i] + nums[j] + nums[left] + nums[right];
                    // long tempSum = 
                    // 0L + nums[i] + nums[j] + nums[left] + nums[right];

                    if (tempSum > target) { right--; }
                    else if (tempSum < target) { left++; }
                    else { // (tempSum == target)
                        res.add(Arrays.asList(
		                        nums[i], nums[j], nums[left], nums[right]
                        ));

                        while (left < right && nums[right] == nums[right-1]) {
		                        right--; 
                        }
                        while (left < right && nums[left] == nums[left+1]) { 
		                        left++; 
                        }

                        right--;
                        left++;
                    }
                }
            }
        }

        return res;
    }
}
```

## 一个非常狡猾的例子：

- 要么剪枝，要么用**long**来防止**位溢出**
- 原因：这组数据里
    - `nums = [1000000000, 1000000000, 1000000000, 1000000000]`
    - 四个数真实数学和：`4,000,000,000`
    - 但 `int` 最大是 `2,147,483,647`，所以 `4,000,000,000` 用 `int` 计算会溢出，变成：
        - `4,000,000,000 - 2^32 = -294,967,296`
