<aside>
💡

Given an integer array `nums` of **unique** elements, return *all possible* *subsets* *(the power set)*.

The solution set **must not** contain duplicate subsets. Return the solution in **any order**.

</aside>

# Thought

- Nature:
    - auto stop
    - no trim, traverse whole tree
- Backtrack recursion design:
    - return void, take idx as current number index
    - base case: no base case needed, auto stop
    - steps:
        - loop numbers from start index, add each number into path
        - add path to `res`
        - do backtrack
- Tree:

```
start idx=0
path=[]            -> add []

i=0 选1
└── path=[1]       -> add [1]
    idx=1
    |
    ├── i=1 选2
    │   └── path=[1,2]     -> add [1,2]
    │       idx=2
    │       |
    │       └── i=2 选3
    │           └── path=[1,2,3]   -> add [1,2,3]
    │           backtrack, remove 3
    │       backtrack, remove 2
    |
    └── i=2 选3
        └── path=[1,3]     -> add [1,3]
        backtrack, remove 3
    backtrack, remove 1

i=1 选2
└── path=[2]       -> add [2]
    idx=2
    |
    └── i=2 选3
        └── path=[2,3]     -> add [2,3]
        backtrack, remove 3
    backtrack, remove 2

i=2 选3
└── path=[3]       -> add [3]
    backtrack, remove 3
    
output:
[]
[1]
[1,2]
[1,2,3]
[1,3]
[2]
[2,3]
[3]
```

# Solution

```java
class Solution {
    List<List<Integer>> res = new ArrayList<>();
    List<Integer> path = new ArrayList<>();

    public List<List<Integer>> subsets(int[] nums) {
        res.add(new ArrayList<>());
        backtrack(nums, 0);
        return res;
    }

    private void backtrack(int[] nums, int idx) {
		    // res.add(new ArrayList<>(path)); <--put here would also works
        for (int i = idx; i < nums.length; i++) {
            path.add(nums[i]);
            res.add(new ArrayList<>(path));
            
            backtrack(nums, i + 1);
            path.remove(path.size() - 1);
        }
    }
}
```
